# Adjacent-word timing interaction

This document describes source behavior and verification requirements. It does not publish historical execution records or attest to a passing run.

The word-timing journey now has interior-word and adjacent-word portions.

The new portion imports a real synthetic four-second WAV through the existing decoder boundary, with a literal three-second scene-clamped clip. Real word chips switch between pending raw time strings. Cancel preserves every loaded/saved field and exact dates. A fresh sheet rejects overlapping adjacent words, retains both drafts, accepts correction in the same sheet, and saves once. The other word, text, cues, audio metadata and decoded-input identity remain unchanged. Editor and document reopen verify persistence.

This is not literal equivalence to the five-second legacy fixture, hardware input, native-menu presentation, direct singular helper coverage, or automatic retirement acceptance.
