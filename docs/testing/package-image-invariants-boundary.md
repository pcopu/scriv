# Finite package image invariants

The native CLI scenario includes semantic prompt disclosure by default.

AUT-J08's package-image-invariants entrypoint stages one checked-in synthetic
package and opens it using the actual Projects browser. Staging is fixture
preparation, not a production import, model setter, repository save, file picker
or persistent-access grant. The CLI advertises it separately from application
commands. Production browser Open performs ordinary decoding and validation.

The finite token permits no caller paths, bytes, names or model fields. A fresh
internally generated project UUID is used. Descriptor-relative exclusive file
creation, exact bounded manifests, private ownership/modes, inode checks and
exclusive atomic rename prevent overwriting existing packages. Publication is
latched before a later durability error. Failure cleanup touches only known,
matching unpublished inodes; a published package is never rolled back.

The literal fixture preserves the frozen ImageInspectorInvariantTests nested
identities, initializer-generated words/timing, nil character links, empty
character/audio collections, overlapping anchored cues, manual/captured prompts,
image lineage and filenames. Actual two-by-two PNG bytes necessarily replace
fake one-byte hashes. Dates and constructor-generated identities are fixed.
The image observer's filename exception is limited to this process's staged
project UUID and exact asset ID/name/hash triples; ordinary digest filenames
retain their existing rule and byte/decoder validation.

Candidate ::0001 assertions are checked after selecting the foreground's
historical version, with full saved and loaded content comparisons. Candidate
::0003 starts from restored fixture content, changes the background's image,
then seeks 500, 1500 and 2500 ms through the real transport slider and observes
the actual preview cue label. Normal accepted-action revision/modifiedAt changes
are checked separately. The `journeys/package-image-invariants` selector also
renders the stored manual and captured prompts on the two image versions in
::0002. It checks semantic Show and Hide actions, explicit missing-prompt text,
and rejection of clipboard and sharing requests. The exploratory UIKit
accessibility route remains available with `--with-prompts` when running the
journey directly.

These are candidate mappings, not acceptance. Native nil-link preservation,
control reachability, compilation and all full-model assertions must pass before
an independent frozen-assertion audit can authorize removal. No provider,
network, external package picker, bookmark restoration, physical input, crash
recovery or composited-pixel equivalence is claimed.
